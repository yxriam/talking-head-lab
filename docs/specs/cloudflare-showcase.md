# Cloudflare 全天在线展示站规格

- 日期/时区、版本：2026-11-02，America/Los_Angeles；1.0
- 需求来源：用户要求 Ray 老师随时可以看到项目，并已登录 Cloudflare 继续配置。
- 初始状态与基线：隔离 worktree `D:/project/facebook/talking-head-lab-pages`，分支 `deploy/cloudflare-showcase`，基线 `origin/main@1ca7a65`；原工作区存在大量未提交改动，本任务不得触碰。

## 目标与边界

目标：新增一个无需本机、WSL 或 GPU 在线即可访问的静态中文展示站，可由 Cloudflare Pages 从 GitHub 自动构建。

范围：`showcase/`、本规格、对应变更记录与 `docs/AI-HANDOFF.md`。非目标：不把 FastAPI、视频生成、检测或 Facebook 采集迁移到云端；不改变现有工作台；不发布个人照片、声音、凭据或运行数据。

约束：只使用仓库已经公开且来源记录为合成/授权的展示素材；页面明确区分“全天在线展示”与“需要本地 GPU 的实时实验室”；无外部前端依赖和第三方统计；部署凭据不进入 Git。

## 输入/输出契约

输入：仓库 README 和 `docs/showcase/` 中已有的公开合成素材与既有实测说明。

输出：`showcase/dist/` 静态站点，包含项目流程、生成样例、检测说明、能力边界、GitHub 源码链接与实时实验室状态说明。构建不得依赖本地 API。
