## 回写的教训

1. 先有冻结规格再做模型试验；不能靠反复追加指令替代验收设计。
2. 原始事实传递必须保留相关时间，不让布尔标签替代证据对。
3. 将控制声明与行为不一致具体写出来；不能用一般身份提醒替代最关键的防范缺口。
4. 不把状态变化、能用邮箱与不熟悉技术等兼容描述误判为矛盾。
5. 原文、手工草稿、模型输出、代码前缀和部署状态分别记录；旧结果不是新需求的成功证明。
6. Git 或独立审查工具不可用时如实留缺口，以快照/diff 保持可审查，不伪造完成状态。
