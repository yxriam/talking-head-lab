# 本地 AI 媒体实验室：界面设计

先实现可浏览界面，再核对本地模型并接入真实推理。沿用现有 React / Vinext 项目，在 /studio 下新增工作区，保留原首页的信号初筛。仅本地运行，不上传人物素材至外部服务。

## 页面与流程

- `/studio`、`/studio#voice`：音色克隆，默认入口及导航首项。参考语音、文字 → 生成语音 → 播放、下载、直接带入人像视频。用户所指语音转换为参考音色的文字转语音。
- `/studio#video`：AI 人像视频，导航第二项。照片、克隆完成的驱动语音 → 生成视频 → 播放、下载、送入检测。此页没有文字输入，也不以参考录音代替克隆输出。可另行上传驱动语音。可加载本地瑞老师素材；现有成片只标注为历史合成示例。
- `/studio#detect`：媒体真伪检测。上传独立媒体或接收生成结果 → 五种学术方法逐项运行 → 并列显示独立阈值、判定、原始模型输出和方法限制。检测不读取生成来源作为预测输入。

## 视觉与交互

参考 ChatGPT 的简单侧栏与输入布局、GPTZero / Turnitin 的结果层级，采用中性白与浅灰、深绿色主操作，14px 标签与16px正文。左侧固定三项导航，右侧限制内容宽度；小屏导航转为顶部。无账号、历史、收费、社交或额外工具。

上传支持选择与拖放、文件名与媒体预览、替换。每页仅一个主按钮。字段完整前禁用主操作，运行时显示真实阶段而不是伪造百分比。失败显示具体原因且保留输入。尚未接入的模型说明未就绪，不生成随机结果。

结果空态与加载态保持稳定容器。检测结果包括真实倾向、AI 倾向、不确定；模型分歧与域外输入不得被多数投票包装成可靠结论。视频同时显示连续异常帧和异常帧占比。论文性能不等同于当前样本的正确概率。

## 硬件核实

2026-09-09：NVIDIA GeForce RTX 5070 Ti Laptop GPU；12227 MiB 显存；compute capability 12.0；驱动573.29，驱动报告CUDA12.8。现有 Chatterbox + SadTalker 脚本针对远端Linux，不能声称已本地部署。后续需实测兼容该GPU的PyTorch。

检测方法名称在核实官方权重、预处理与本机推理后确定。UI阶段仅三个待接入席位，不把传统频域/运动统计伪装成已验证分类器。

## 生成结果直接检测

视频预览下方提供“检测这个视频”。未生成时禁用；生成成功后传递同一个本地视频资源至检测页，自动填入视频，无需下载与重新上传。生成完成响应提供资源，检测只分析媒体内容。当前已实现 UI 与资源传递逻辑，尚无真实生成结果供端到端验证。
